# Clean Ocean - The Game

Endless runner 2D con temática medioambiental. 
El jugador controla un buzo que recoge basura 
esquivando tiburones.

**Publicado en Google Play — Nivix Studio**
[Descargar en Google Play]
https://play.google.com/store/apps/details?id=com.NivixStudio.CleanOcean&pcampaignid=web_share

## Stack
- Unity 2D / C#
- Assets: Kenney.nl
- Plataforma: Android

## Mi rol
Desarrollo completo en solitario: gameplay, 
UI, HUD, menú y efectos.

## Scripts destacados
- `PlayerHealth.cs` — colisiones y efectos visuales y musicales
- `GameManager.cs` — sistema general del juego
- `SaveScoreScript.cs` — sistema de guardado de puntuación
